### 🌊 About Me & The Stellar Wave Mission

Hey there! I am **Harsh**, an enthusiastic software engineer and dedicated open-source contributor actively participating in the **Stellar Wave Program** on **Drips Network** (`drips.network`).

My mission is to strengthen open-source infrastructure across the **Stellar** and **Soroban** ecosystems by solving critical repository issues, developing smart contracts, improving developer tooling, and building seamless decentralized experiences.

- 🔭 **Active Focus**: Participating in monthly 7-day **Stellar Drips Wave sprints**.
- 🛠️ **What I Deliver**: High-quality bug fixes, Soroban smart contract development, TypeScript SDK integrations, and comprehensive test suites.
- 📐 **Engineering Principles**: Clean code, Test-Driven Development (TDD), zero regressions, and transparent communication.
- 🤝 **Collaboration**: Always ready to assist maintainers and review ecosystem initiatives.

---

### 🛡️ Why Maintainers Can Count on My PRs

Maintainers evaluating my wave applications can expect institutional-grade contributions:

| Standard | Commitment |
| :--- | :--- |
| **🔗 Explicit Issue Linking** | Every PR strictly links `Closes #XYZ` ensuring seamless automated tracking by the Drips Wave bot. |
| **🧪 Rigorous Testing** | All code changes include unit, integration, or end-to-end (E2E) tests with regression prevention. |
| **📝 Conventional Commits** | Commits strictly adhere to standard semantics (`feat:`, `fix:`, `test:`, `docs:`, `refactor:`). |
| **⏱️ Timely Delivery** | Solutions are submitted ahead of the 7-day wave sprint deadlines to allow adequate maintainer review. |
| **📖 Clear Documentation** | Every PR features detailed description, reproduction steps, architectural choices, and verification proof. |
